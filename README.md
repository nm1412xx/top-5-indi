# Top 5 Juegos Indie

Sitio web de ranking sobre cinco juegos indie destacados.

## Descripción

Este proyecto presenta un top 5 de juegos indie, explicando por qué cada juego ocupa su posición dentro del ranking. La página incluye imágenes clickeables y descripciones breves de cada título.

## Ranking incluido

1. Hollow Knight
2. Celeste
3. Undertale
4. Stardew Valley
5. Dead Cells

## Tecnologías utilizadas

- HTML5
- CSS3
- GitHub Pages

## Objetivo

Crear una página de ranking con contenido organizado, imágenes, descripciones y una estructura clara para el usuario.
